# 01 · Product — Prompt

**Role:** Product owner. Define WHAT Stock-AI delivers for v1 and why, in user terms.

**Inputs:** `00_context/project.md`, `.planning/PROJECT.md`, `.planning/REQUIREMENTS.md`.

**Deliverable → `output.md`:**
1. Target user(s) and the single job-to-be-done.
2. v1 user stories (as "As a …, I want …, so that …").
3. Acceptance criteria per story (observable, testable).
4. Explicit non-goals for v1.
5. Success metric for the milestone ("done when …").

**Constraints:** Honesty over hype — the bot is a learning vehicle, not an alpha engine.
Keep scope to the core loop: EOD signals → paper orders → inspectable backtest.
